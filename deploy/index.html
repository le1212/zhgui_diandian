四大核心能力

四种形态，一条轨迹

从一次连点到一套自动化流程，所有操作共用同一条执行路径，混合点击、等待、键盘、滚轮与图像定位。

真实录制

基于 Raw Input 消息驱动，不安装低级鼠标 Hook。鼠标点击、键盘按下/松开、滚轮滚动，全部录成步骤。

多点任务

步骤可双击编辑、复制、拖拽排序、启用/禁用、删除、Ctrl+Z 撤销。运行前生成不可变快照，运行中禁止改任务。

图像定位

在桌面截图上框选文字或图标作为模板，运行时在全部显示器中匹配模板中心并点击。找不到目标会停在相似度最高处。

安全可控

F2 全局捕获屏幕坐标，F6 启停、F7 暂停、Esc 紧急停止。任务进回收站可恢复，schema v2 原子写入 + 5 份自动备份。

性能设计

它从不站在画面中央

点点是一个真正的 Windows 桌面程序，但它学会了退场——不抢输入链路、不阻塞主线程、不假设 DPI。

录制器不安装全局低级鼠标 Hook，基于 Raw Input 消息驱动，纯移动事件直接忽略，不阻塞 Windows 输入链路。

独立录制线程只在点击、滚轮或按键事件到达时读取坐标和窗口信息，空闲时零开销。

工作线程不直接访问 Tk 控件，所有界面更新通过线程安全队列回到主线程，播放前生成不可变执行计划。

启用 Per-Monitor DPI Awareness，兼容多显示器与不同缩放比例；PyInstaller 单文件构建，用户无需安装 Python。

常见问题

你想知道的，都在这里

点点连点器是什么？

点点是一款基于 Win32 SendInput API 的 Windows 桌面鼠标连点器。它通过真实系统输入接口模拟鼠标点击，支持单点、多点任务编排、鼠标录制、键盘滚轮录制和图像定位点击。与低级 Hook 类工具不同，点点使用 Raw Input 录制，不安装全局钩子，安全可控。

点点安全吗？会被反作弊检测吗？

点点不安装全局低级鼠标 Hook，录制阶段使用 Raw Input 读取原始输入；运行时通过 SendInput 注入系统级真实事件。任务数据仅保存在本地 %APPDATA%\Diandian 目录，不上传任何信息。请在合规场景下使用。

点点支持多显示器和不同 DPI 吗？

支持。点点启用了 Per-Monitor DPI Awareness，可在不同 DPI 缩放比例的多显示器间精确定位坐标。图像模板匹配功能会在所有显示器区域内搜索目标图案并自动点击。

点点需要安装 Python 吗？是免费的吗？

不需要。点点通过 PyInstaller 构建为单文件 Diandian.exe，双击即可运行，目标机器无需安装 Python 或任何依赖。个人使用完全免费。

点点的快捷键有哪些？

F2 捕获当前鼠标坐标并记录目标窗口；F6 开始或停止当前任务；F7 暂停或继续当前任务；Esc 紧急停止并恢复主窗口。所有快捷键在任意前台窗口均可全局生效，无需切换到点点主界面。
